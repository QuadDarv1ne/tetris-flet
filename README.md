# TETRIS — полнофункциональный клон на Python/Flet

Игра "Тетрис" с современной механикой: 5 режимов игры, T-spin, Combo,
Back-to-Back, таблица рекордов, статистика сессии, официальная музыка
"Коробейники" и звуковыми эффектами.

---

## Возможности

### Режимы игры (5)
| Режим | Описание |
|---|---|
| **1 игрок — Marathon** | Классический бесконечный режим, уровень растёт каждые 10 линий |
| **2 игрока — Co-op** | Два игрока на одной клавиатуре, отдельные поля |
| **2 игрока — Battle** | Очищай 2+ линии, чтобы забросать противника garbage-строками; партия заканчивается победой или ничьей при вылете |
| **Sprint — 40 линий** | Очисти 40 линий как можно быстрее (цель — минимальное время) |
| **Ultra — 120 сек** | Собери максимум очков за 2 минуты (обратный отсчёт) |

### Игровая механика
- **7-bag рандомизатор** — честное распределение фигур (как в Tetris Guideline)
- **7 фигур** (I, O, T, S, Z, L, J) с каноническими цветами
- **SRS-подобные wall kicks** при повороте (фигура может "выскользнуть" из стены)
- **Hold** — отложенная фигура (один раз за спавн)
- **Ghost piece** — тень, показывающая место падения (можно отключить)
- **Soft drop** (+1 очко/клетка) и **Hard drop** (+2 очко/клетка)

### Сложная техника
- **T-spin** — поворот T-фигуры в позицию, где ≥3 из 4 диагональных углов
  заняты. Бонусы: T-spin Single (800×level), Double (1200×level),
  Triple (1600×level), без линий (400×level)
- **Combo** — подряд идущие очистки линий дают +50×combo×level за каждый
- **Back-to-Back (B2B)** — подряд идущие Tetris или T-spin дают +50% бонус
- **Garbage в Battle** — T-spin Single/Double/Triple и B2B Tetris отправляют
  противнику +1 garbage-строку

### Интерфейс
- Тёмная тема с неоновыми акцентами (cyan/amber/purple)
- Панель игрока: счёт, линии, уровень, HOLD, следующие 3 фигуры,
  индикаторы T-spin/Combo/B2B
- Таймер для Sprint (нарастающий) и Ultra (обратный отсчёт, краснеет <10 сек)
- Прогресс-бар для Sprint (линии/40) и Ultra (оставшееся время)
- Сенсорные кнопки для мобильных устройств во всех одиночных режимах

### Дополнительные функции
- **Таблица рекордов** (топ-10) — отдельный рейтинг для каждого режима,
  сохраняется между запусками в `~/.tetris_flet_leaderboard.json`
- **Статистика сессии** — PNG-отчёт с графиками matplotlib: распределение
  очисток, T-spin/Combo/B2B, сводка, эффективность (TPS, LPM, Tetris-rate)
  Время Marathon/Co-op/Battle учитывается с начала партии без пауз;
  Sprint/Ultra запускают таймер с первого действия.
- **Сохранение настроек** — имя игрока, звук, музыка, ghost, уровень,
  последний режим — в `~/.tetris_flet.json`
- **Музыка** — официальный MP3 "Коробейники" (зацикленный) с fallback
  на синтезированный WAV
- **9 звуковых эффектов** — move, rotate, lock, hard_drop, line_clear,
  tetris, level_up, hold, game_over

## Установка

### Требования
- Python 3.10+
- Linux / macOS / Windows
- Графическая подсистема (X11/Wayland на Linux, нативное окно на Win/Mac)

### Установка зависимостей

```bash
pip install -r requirements.txt
```

Звук работает на Windows через встроенный MCI-бэкенд и не требует
`flet-audio`. На Linux и macOS игра запускается без воспроизведения звука.
Ползунок громкости доступен для MP3; WAV-fallback воспроизводится на полной
громкости без регулировки.

> **Примечание**: `matplotlib`, `pillow` и `numpy` нужны только для экрана
> статистики сессии. Игра работает и без них — статистика будет отключена.

## Запуск

```bash
cd tetris-flet    # папка с tetris_flet.py и assets/
python tetris_flet.py
```

При первом запуске создаются:
- `~/.tetris_flet.json` — настройки
- `~/.tetris_flet_score.json` — лучший счёт
- `~/.tetris_flet_leaderboard.json` — таблица рекордов

## Управление

### Игрок 1 (все режимы)
| Клавиша | Действие |
|---|---|
| `A` / `D` | движение влево / вправо |
| `W` | поворот (T-spin если последняя фигура T после поворота) |
| `S` | мягкое падение (+1 очко/клетка) |
| `Space` | hard drop (мгновенное падение, +2 очко/клетка) |
| `Q` | hold (отложенная фигура, 1 раз за спавн) |

В одиночных режимах также работают стрелки: `←` / `→` — движение,
`↑` — поворот, `↓` — мягкое падение. Удержание клавиши повторяет действие
с системной частотой автоповтора клавиатуры. На сенсорных кнопках движение
и мягкое падение также повторяются, пока кнопка удерживается.

### Игрок 2 (режимы Co-op / Battle)
| Клавиша | Действие |
|---|---|
| `←` / `→` | движение влево / вправо |
| `↑` | поворот |
| `↓` | мягкое падение |
| `Enter` | hard drop |
| `Right Shift` | hold |

### Общие
| Клавиша | Действие |
|---|---|
| `P` | пауза |
| `R` | рестарт (применяет настройки и стартовый уровень) |
| `M` | вкл/выкл музыку |
| `N` | вкл/выкл звук |
| `L` | таблица рекордов |
| `T` | статистика сессии (PNG-отчёт) |
| `Ctrl+S` | настройки (или кнопка ⚙) |
| `Esc` | выход |

## Система очков

| Действие | Очки |
|---|---|
| Очистка 1 линии (Single) | 100 × level |
| Очистка 2 линий (Double) | 300 × level |
| Очистка 3 линий (Triple) | 500 × level |
| Очистка 4 линий (Tetris) | 800 × level |
| Soft drop | +1 за клетку |
| Hard drop | +2 за клетку |
| T-spin без линий | 400 × level |
| T-spin Single | 800 × level |
| T-spin Double | 1200 × level |
| T-spin Triple | 1600 × level |
| Combo (подряд идущие клиры) | +50 × combo × level |
| Back-to-Back (Tetris/T-spin подряд) | +50% от базовых очков |

**Уровень** = `стартовый_уровень + линии // 10`. Чем выше уровень, тем
быстрее падают фигуры (интервал: `max(0.08, 0.8 - (level-1)*0.07)` сек).
В Sprint/Ultra гравитация дополнительно ускорена ×0.85.

## Режимы детально

### Marathon (1P)
Бесконечная игра. Цель — набрать максимум очков до top-out.
Рекорд сохраняется в `~/.tetris_flet_score.json`.

### Co-op (2 игрока)
Два независимых поля на одном экране. Каждый играет за себя,
garbage не пересылается. Хорошо для совместной тренировки.

### Battle (2 игрока)
Очищай 2+ линии, чтобы отправить противнику garbage:
- Double → 1 строка, Triple → 2, Tetris → 3
- T-spin Single → 2, T-spin Double → 2, T-spin Triple → 3
- B2B Tetris/T-spin → +1 строка

Garbage добавляется снизу со случайной дырой. Если противник
тоже очищает линии в этом же кадре — garbage взаимно компенсируется.

### Sprint (40 линий)
Цель — очистить 40 линий как можно быстрее. Таймер запускается
с первого действия игрока (честно — нельзя "подготовить" поле).
Победа фиксирует время, рекорд сортируется по возрастанию.
Пауза останавливает таймер.

### Ultra (120 секунд)
Цель — набрать максимум очков за 2 минуты. Таймер обратного
отсчёта, краснеет при <10 сек. По истечении — экран "ВРЕМЯ ВЫШЛО!"
с финальным счётом. Пауза останавливает обратный отсчёт.

## Решение проблем

### Музыка не играет
- Проверь, что `assets/audio/music_korobeiniki.mp3` существует
- В Windows в консоли должен быть лог `[audio] музыка: официальный MP3 (MCI)`
- Нажми `M`, чтобы включить музыку

### Звук не работает
- Воспроизведение звука через MCI доступно только в Windows.
- На Windows проверь, что файлы есть в `assets/audio/`.
- На Linux и macOS звук в текущей версии отключён.

### Статистика не генерируется
Нужны `matplotlib`, `pillow`, `numpy`:
```bash
pip install matplotlib pillow numpy
```

### Окно не открывается (Linux)
Убедись, что есть дисплей:
```bash
echo $DISPLAY   # должно быть :0 или类似
```
В headless-окружении используй `xvfb-run python tetris_flet.py`.

### Шрифты не отображают кириллицу
На Linux установи Noto Sans SC:
```bash
apt install fonts-noto-cjk   # или fonts-noto-cyrillic
```

## Авторские решения

- **Asset-путь для MP3**: вместо base64 (4.4 МБ строка) используется
  `page.assets_dir` + относительный путь — быстрее загрузка, меньше
  памяти
- **7-bag рандомизатор**: гарантирует, что игрок не получит >2
  одинаковых фигур подряд (как в настоящем Tetris)
- **T-spin детекция по углам**: проверка 4 диагональных углов вокруг
  центра T-фигуры — каноничное правило из Tetris Guideline
- **Ленивый импорт matplotlib**: статистика грузится только при
  нажатии кнопки, чтобы игра запускалась даже без matplotlib
- **Combo/B2B с garbage-бонусами**: B2B Tetris отправляет +1 garbage
  в Battle-режиме — стимул играть технично
